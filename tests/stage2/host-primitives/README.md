# Stage 2 private host operations

`task stage2-pair-host-primitives` executes the maintained C compiler and the
canonical Kofun compiler against one versioned fixture, `cases.json`. It
compares complete emitted C, compiles it under strict C11, and checks runtime
output. Parameters and locals retain their HIR binding IDs; function names,
module constants, record types and fields use the same `k_uXXXXXX` spelling.

The Kofun side runs through `bootstrap/stage2/host-driver.mjs`. The driver loads
the trusted compiler source, parses its closed bootstrap statement/expression
subset, and binds the existing public runtime operations plus exactly two
compiler-private operations. Input programs remain byte-wise Text data. Their
calls are resolved by `compiler.kofun`, not by the driver's JS environment.
The driver is a bounded execution path for the pair gate, not a claim that
Stage 2 can natively compile itself or that the whole language is implemented
in JavaScript. The native self-compilation issue remains #1483.

`stage2_unicode_scalar_at` yields an Int scalar or a typed host failure with
separate index, end, continuation, malformed, overlong, surrogate, and range
cases. The C host uses a tagged result; the Kofun driver raises
`HostOperationError`. The identifier predicates consume the scalar and the
pinned Unicode 17 range tables generated by `generate-xid.mjs`. Neither `chars`
nor an ordinary source program gains numeric byte access.

`stage2_same_file` yields Same (1), Different (0), or a typed lookup refusal.
Text equality comes first, then input `stat`, then output `stat`. Only ENOENT
on the output means Different. Final symlinks are followed, and device/inode
values are compared without narrowing. The gate covers every writer, including all three ordinary compiler output
paths, and identity and lookup refusal precedence over digest
validation and source reads. A missing output is written successfully through
the real HIR writer. Failed lookups and aliases preserve the input and any
existing output bytes.

The native fixture injects lookup failures only inside its own translation
unit; production code has no environment-controlled failure or guard bypass.
The same versioned fixture runs on each half. Independent production-source
mutations remove C and Kofun scalar handling and identity guards. Each Kofun
escaping dispatch is then bypassed separately to prove that the fixture set
covers every route. Mutation builds must compile successfully before a behavior
comparison can count as detecting a defect.

The pair comparison also exposed two small prerequisites: the Kofun C prelude
omitted one blank line, and labelled record construction could ask for a
function's parameters at a missing declaration. The prelude bytes now match,
and both halves stop that parameter lookup before reading a negative offset.

After a serialized pair edit, `task stage2-pair-refresh` regenerates the XID
projection, checksums, and manifest seed digest. `task release-evidence` owns
the separate release evidence pack.
